TUNE - music player app (audio only from YouTube)

1. Install Flutter (docs.flutter.dev) and Android Studio. Run: flutter doctor --android-licenses
2. Double-click BUILD_APK.bat
3. Wait. When finished, Tune.apk appears in this folder.
4. Copy Tune.apk to your phone and install it.

To edit the app in Android Studio: File > Open > this folder (after the first build).
